05. 语法合法，不等于字段能用。

五段真实形状的返回，四档约束强度。切换档位看每一段停在哪一关——解析失败要进兜底，脏数据不能进下游。

当前档位能安全交给下游的样本
0 / 5 没有任何程序边界

校验失败之后去哪

本地校验：JSON Schema / Jackson 校验字段、类型、必填、枚举。这一步挡掉的是脏数据，不是模型态度。
轻量修复：只补格式——截断补齐、前后缀剥离，不重新生成业务内容。
降级 Schema：一个大对象拆成两次小抽取，先分类再抽字段，用复杂度换通过率。
规则或人工兜底：订单、金融、医疗、法务不要完全交给自动修复。

一张 Schema 买到什么

{ "intent": "refund_request", "confidence": 0.86, "entities": { "order_id": "202605080001" }, "need_human_review": false }

有了 Schema，后端才敢假设：intent 是有限枚举、confidence 是数字、order_id 可空但类型稳定、need_human_review 一定存在。

能展示给用户 ≠ 能被程序执行。失败时不要把原始自然语言硬塞给下游。
