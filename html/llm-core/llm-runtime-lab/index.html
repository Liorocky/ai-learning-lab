01. Token 不是字符，也不是词。

Tokenizer 用子词把输入拆成模型能处理的离散 ID。不同模型、不同词表，切法和成本都可能变。

输入试验台

模型真正看到的形状

messages = [ { role: "system", content: "..." }, { role: "user", content: "你的输入" } ] token_ids = [ 101, 4930, 11, ... ] next_token = model(token_ids)

这里是教学用的近似分词，不是任何供应商的官方计数器。生产环境请读 API 的 usage 或用官方 tokenizer；工具 schema、消息边界等不可见 Token 同样占用窗口。

03. 塞进窗口，不等于被同等利用。

长上下文常有“中间丢失”：开头与结尾的信息更容易被召回。点击一条约束，体验它在不同位置的可见性。
